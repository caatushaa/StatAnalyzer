# StatAnalyzer

Приложение для статистического анализа данных с прогнозированием методом экстраполяции по скользящей средней.

## Модули

### ВВП и ВНП России (Автор: [твоё имя])
- Загрузка данных из JSON-файла
- Отображение в таблице
- Графики ВВП и ВНП по годам
- Расчёт максимального роста и падения за год
- Прогнозирование на N лет методом скользящей средней
- Экспорт графика в PNG/SVG

### Качество дорог по субъектам (Автор: [имя коллеги])
- Загрузка данных из JSON-файла
- Отображение в таблице
- Графики по субъектам РФ
- Определение субъектов с максимальным и минимальным улучшением дорог
- Прогнозирование на N лет для выбранного субъекта
- Экспорт графика в PNG/SVG

## Структура веток
- `main` — стабильная версия
- `dev` — ветка разработки
- `feature/gdp-analysis` — модуль ВВП/ВНП
- `feature/roads-analysis` — модуль качества дорог

## Технологии
- C# / Windows Forms / .NET
- ScottPlot (графики)
- Newtonsoft.Json (парсинг данных)
